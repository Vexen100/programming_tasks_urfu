# Парсер вакансий HeadHunter

Веб-приложение для получения и отображения вакансий с HeadHunter API, реализованное на Django.

## Структура проекта

- `parser.py` - скрипт для получения данных с HH API и сохранения в базу данных через Django ORM
- `hh_api/` - Django-приложение для отображения вакансий
  - `works/` - основное приложение с моделями и представлениями
  - `templates/` - HTML-шаблоны для отображения

## Функциональность

✅ Получение вакансий с HeadHunter API через GET-запросы  
✅ Сохранение полной информации о вакансиях в базу данных  
✅ Каталог всех вакансий с постраничной навигацией  
✅ Поиск вакансий по ключевым словам (название, описание)  
✅ Фильтрация по категориям, городам и работодателям  
✅ Сортировка по дате публикации и зарплате  
✅ Детальная информация о каждой вакансии с полным описанием  

## Быстрый старт

### Минимальные команды:

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Настроить базу данных
cd hh_api
python manage.py migrate

# 3. Получить данные с HH API (вернуться в корень проекта)
cd ..
python parser.py

# 4. Запустить сервер
cd hh_api
python manage.py runserver
```

Откройте браузер: **http://127.0.0.1:8000/**

📖 **Подробная инструкция:** см. `SETUP_INSTRUCTIONS.md`  
⚡ **Быстрая справка:** см. `QUICK_START.md`

### Что можно делать:

- **Каталог вакансий** - просмотр всех вакансий с пагинацией
- **Поиск и фильтры** - поиск по ключевым словам, фильтрация по категориям, городам, работодателям и сортировка
- **Детальная информация** - полное описание вакансии при клике на неё

## Технические детали

- **Django 4.2** - веб-фреймворк
- **SQLite** - база данных
- **HeadHunter API** - источник данных о вакансиях
- **Django ORM** - для работы с базой данных
