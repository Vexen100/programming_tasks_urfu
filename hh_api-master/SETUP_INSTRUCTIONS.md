# Инструкция по запуску проекта

## Шаг 1: Установка зависимостей

Откройте терминал в корневой папке проекта и выполните:

```bash
pip install -r requirements.txt
```

Это установит все необходимые библиотеки:
- Django 4.2.27
- requests (для работы с API)
- и другие зависимости

## Шаг 2: Настройка базы данных

Перейдите в папку `hh_api` и выполните миграции:

```bash
cd hh_api
python manage.py migrate
```

**Важно:** Если у вас уже есть база данных `db.sqlite3` со старыми данными, рекомендуется:
1. Сделать резервную копию (если нужны данные)
2. Удалить файл `db.sqlite3`
3. Выполнить миграции заново

## Шаг 3: Получение данных с HeadHunter API

Вернитесь в корневую папку проекта и запустите парсер:

```bash
cd ..
python parser.py
```

Парсер будет:
- Получать вакансии с HeadHunter API (10 страниц по 100 вакансий)
- Для каждой вакансии получать детальное описание
- Сохранять всё в базу данных

**Время выполнения:** Процесс может занять 5-15 минут в зависимости от скорости интернета.

Вы увидите прогресс в консоли:
```
Начало парсинга вакансий с HeadHunter...
Получено 1000 вакансий для обработки
Обработано 50/1000 вакансий...
Обработано 100/1000 вакансий...
...
Парсинг завершен. Сохранено вакансий: 950
```

## Шаг 4: Запуск веб-сервера

Оставайтесь в папке `hh_api` и запустите сервер разработки:

```bash
cd hh_api
python manage.py runserver
```

Вы увидите сообщение:
```
Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
```

## Шаг 5: Проверка работы

Откройте браузер и перейдите по адресу: **http://127.0.0.1:8000/**

### Что можно проверить:

1. **Каталог вакансий** (главная страница):
   - Должны отображаться все вакансии
   - Внизу должна быть пагинация (если вакансий больше 10)
   - Можно кликнуть на название вакансии для просмотра деталей

2. **Поиск и фильтры** (кнопка "Поиск и фильтры" в меню):
   - Поиск по ключевым словам (например: "Python", "разработчик")
   - Фильтрация по категориям
   - Фильтрация по городам
   - Фильтрация по работодателям
   - Сортировка (новые, по зарплате)
   - Комбинация всех фильтров

3. **Детальная страница вакансии**:
   - Полное описание вакансии
   - Информация о компании, городе, категории
   - Зарплата (если указана)

4. **Админ-панель Django** (опционально):
   - Откройте http://127.0.0.1:8000/admin/
   - Создайте суперпользователя: `python manage.py createsuperuser`
   - Войдите и проверьте данные в базе

## Возможные проблемы и решения

### Проблема: "ModuleNotFoundError: No module named 'django'"
**Решение:** Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`

### Проблема: "No such table: works_vacancy"
**Решение:** Выполните миграции: `cd hh_api && python manage.py migrate`

### Проблема: "ConnectionError" при запуске parser.py
**Решение:** Проверьте интернет-соединение. API HeadHunter должно быть доступно.

### Проблема: Парсер работает очень долго
**Решение:** Это нормально. Парсер получает детальную информацию о каждой вакансии отдельным запросом. Можно уменьшить `MAX_PAGES` в `parser.py` для тестирования.

### Проблема: База данных пустая после парсинга
**Решение:** 
- Проверьте, что парсер завершился без ошибок
- Проверьте логи в консоли
- Убедитесь, что миграции выполнены корректно

## Дополнительные команды

```bash
cd hh_api

```

### Просмотр SQL-запросов (для отладки):
```bash
cd hh_api
python manage.py shell
>>> from works.models import Vacancy
>>> Vacancy.objects.count()  # Количество вакансий
```

### Очистка базы данных (удаление всех вакансий):
```bash
cd hh_api
python manage.py shell
>>> from works.models import *
>>> Vacancy.objects.all().delete()
>>> Category.objects.all().delete()
>>> City.objects.all().delete()
>>> Employer.objects.all().delete()
```
